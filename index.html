    About TravelPal

    TravelPal helps you discover and organize your travel destinations.

    Features:

    • Manage your list of best locations
    • Optional AI-powered suggestions using Google Gemini
    • Simple and intuitive interface

    Privacy:

    Your Gemini API key is stored only in your browser's session storage and never sent to any server other than Google's Gemini API. It's cleared when you close your browser.

    Google Gemini API Key Required

    To use AI-powered suggestions, you need a Google Gemini API key. Your key will be stored only in your browser's session storage and will not be shared with any third parties.

    How to get an API key:

    1. Visit Google AI Studio
    2. Sign in with your Google account
    3. Create an API key
    4. Copy and paste it below
