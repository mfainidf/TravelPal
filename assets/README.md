# Assets

This folder contains placeholder image assets for the TravelPal app.

For now, actual images are not required. When building the app, Expo will 
use default placeholders if these specific image files are missing.

Required assets (will use defaults if not provided):
- icon.png (1024x1024)
- splash.png (1242x2436)
- adaptive-icon.png (1024x1024)
- favicon.png (48x48)
