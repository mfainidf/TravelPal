# TravelPal 🌍

Your Complete Journey Planning Companion

## Overview

TravelPal is a comprehensive web application designed to help you plan and manage your tourist journeys. It provides all the tools you need to organize your travel preparations, create baggage checklists, identify the best locations, and plan your entire journey efficiently.

## Features

### 📅 Journey Planning
- Set your travel destination
- Choose start and end dates
- Set a budget for your trip
- Add custom notes about your journey
- View journey summary with duration calculation
- Edit your journey plan anytime

### 📋 Travel Preparation
- Essential preparation checklist including:
  - Passport and visa checks
  - Travel insurance
  - Vaccinations
  - Flight/train bookings
  - Accommodation reservations
  - Currency exchange
  - Bank notifications
  - Document copies
  - Emergency contacts
- Add custom preparation items
- Track completion status for each item

### 🧳 Baggage Checklist
- Pre-organized checklists for:
  - Clothing essentials
  - Toiletries
  - Electronics and documents
- Add custom baggage items
- Check off items as you pack
- Visual completion tracking

### 📍 Best Locations
- Save interesting locations for your trip
- Categorize locations (attractions, restaurants, hotels, activities, shopping)
- Rate locations with 1-5 star system
- Add notes about each location
- Filter locations by category
- Delete locations you no longer need

## How to Use

1. **Open the Application**
   - Simply open `index.html` in your web browser
   - No installation or server required

2. **Plan Your Journey**
   - Navigate to the "Journey Planning" tab
   - Fill in your destination, dates, and budget
   - Click "Save Journey Plan"

3. **Prepare for Travel**
   - Go to the "Travel Preparation" tab
   - Check off items as you complete them
   - Add any custom preparation items specific to your trip

4. **Create Your Packing List**
   - Visit the "Baggage Checklist" tab
   - Review pre-made checklists
   - Add custom items you need to pack
   - Check off items as you pack

5. **Discover Best Locations**
   - Switch to the "Best Locations" tab
   - Add locations you want to visit
   - Rate and categorize them
   - Filter by category to organize your plans

## Technology

- **HTML5** - Structure and content
- **CSS3** - Modern, responsive styling with animations
- **Vanilla JavaScript** - Interactive functionality
- **LocalStorage** - Persistent data storage (no server required)

## Data Persistence

All your data is stored locally in your browser using LocalStorage. This means:
- ✅ Your data persists between sessions
- ✅ No internet connection required
- ✅ Your data stays private on your device
- ⚠️ Clearing browser data will remove your saved information
- ⚠️ Data is device-specific (not synced across devices)
