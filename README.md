# TravelPal

React + TypeScript travel planning application built with Vite.

## Features

- ⚡️ Vite for fast development and build
- ⚛️ React 19 with TypeScript
- 🌍 i18n support with i18next (Italian language)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## i18n Configuration

The application is configured with i18next for internationalization, currently supporting Italian (IT) language:

- Configuration: `src/i18n/index.ts`
- Translations: `src/i18n/it.json`

The framework is ready for future language extensions.
